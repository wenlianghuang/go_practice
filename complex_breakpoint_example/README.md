# 🎯 複雜 Go Breakpoint 調試練習範例

這是一個專門設計用於練習 Go 語言 breakpoint 調試技巧的複雜銀行系統模擬器。系統包含多個業務場景，從簡單的用戶管理到複雜的並發處理，讓你能夠全面練習各種調試技巧。

## 🚀 快速開始

### 1. 安裝依賴
```bash
cd complex_breakpoint_example
go mod tidy
```

### 2. 啟動服務器
```bash
go run main.go
```

### 3. 運行測試腳本
```bash
./test_scripts.sh
```

## 📋 系統功能

### 🏦 核心業務功能
- **用戶管理**: 創建、查詢用戶信息
- **銀行帳戶**: 存款、提款、餘額查詢
- **轉帳系統**: 用戶間資金轉移
- **貸款系統**: 貸款申請和審核
- **交易記錄**: 完整的交易歷史

### ⚡ 並發處理
- **Goroutine 調試**: 異步貸款審核
- **並發操作**: 多個同時進行的金融操作
- **同步機制**: Mutex 和 WaitGroup 的使用
- **Race Condition**: 數據競爭檢測和調試

### 🐛 錯誤處理場景
- **業務邏輯錯誤**: 餘額不足、帳戶鎖定
- **數據驗證錯誤**: 無效金額、重複用戶名
- **系統錯誤**: 隨機處理失敗、超時處理
- **邊界條件**: 極值測試、空值處理

## 🔧 調試工具和技巧

### 斷點類型
- **普通斷點**: 在特定行停止執行
- **條件斷點**: 只在滿足條件時停止
- **日誌斷點**: 記錄信息而不停止執行
- **函數斷點**: 在函數入口處停止

### 調試控制
- **F5**: 繼續執行到下一個斷點
- **F10**: 單步執行，不進入函數
- **F11**: 單步執行，進入函數內部
- **Shift+F11**: 跳出當前函數

### 變量監視
- **Variables 面板**: 查看當前作用域變量
- **Watch 面板**: 監視特定表達式
- **Call Stack**: 查看函數調用順序
- **Debug Console**: 執行 Go 表達式
